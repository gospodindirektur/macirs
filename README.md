# 📻 Macır Mahallesi Canlı Radyo

Bulgaristan, Türkiye ve Almanya'dan en sevilen canlı radyoları tek bir çatı altında toplayan modern, Balkan temalı web radyo platformu.

## ✨ Özellikler
- **Canlı Radyolar:** Radio Veselina, Veselina Retro, Radio Folk BG, Radio Veronika, Kafa Radyo, PowerTürk, Metropol FM Almanya, Pal FM, Best FM.
- **Arka Planda Çalma:** Ekran kapalıyken veya kilit ekranında kesintisiz yayın (MediaSession API & Bildirim kontrolleri).
- **Canlı Saat ve Tarih:** Türkiye (İstanbul), Bulgaristan (Sofya) ve Almanya (Berlin) için anlık canlı saatler ve tarih.
- **Açılış İntrosu:** Macır Mahallesi özel animasyon videosu (Geçilebilir tam ekran intro).
- **Canlı Bilgiler:** Döviz kurları (USD, EUR, Gram Altın) ve 12 Balkan/Türkiye şehrinin anlık hava durumu bandı.
- **Etkileşim:** Şarkı/Radyo favorileme, uyku zamanlayıcısı, ses ayarı, rastgele radyo ve Beğeni sayacı.

## 🚀 GitHub Pages ile Canlıya Alma
1. Bu depoyu GitHub hesabınıza yükleyin (`Upload files` veya `git push`).
2. Deponuzun **Settings > Pages** bölümüne gidin.
3. **Branch** kısmından `main` (veya `master`) seçip **Save** butonuna tıklayın.
4. Siteniz birkaç dakika içinde `https://kullaniciadiniz.github.io/depo-adi/` adresinde yayına girecektir!
