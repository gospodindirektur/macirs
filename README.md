# 📻 Macır Mahallesi Canlı Radyo

Bulgaristan, Türkiye ve Almanya'dan en sevilen canlı radyoları tek bir çatı altında toplayan modern, Balkan temalı web radyo platformu.

## 🎵 Canlı Radyolar
- **Bulgaristan & Balkan:** Radio Veselina, Veselina Retro, Radio Veronika, Radio Nova Bulgaristan.
- **Türkiye:** Süper FM, PowerTürk, Pal FM, Kafa Radyo, Best FM, Küpe FM Silivri, Alem FM, Fenomen Türk, Dream Türk.
- **Almanya:** Metropol FM Almanya.

## ✨ Yeni Özellikler
- **Sıradaki Radyoya Geç Butonu:** Çalan radyonun sağındaki 'Sonraki ⏭️' butonuyla tüm radyolar arasında sonsuz döngüde geçiş yapılır.
- **Dev Çalan Radyo Başlığı & Dalgalanan Harfler:** Çalan radyonun ismi dev boyutta ve canlı dalga dansı (`letterDance`) animasyonuyla parlar.
- **Logonun Yanlarında Animasyonlu Hoparlörler:** Radyo açıldığında bas vurarak sallanan 3D kabin hoparlörler.
- **3D Dikey Kayan Piyasa Paneli:** Dolar, Euro ve Altın kuru yukarıdan aşağıya akıcı geçişle değişir.
- **Kesintisiz Kayan Canlı Hava Durumu:** 12 şehir için donmayan canlı hava durumu şeridi.

## 🚀 GitHub Pages ile Canlıya Alma
1. Bu depoyu GitHub hesabınıza yükleyin (`Add file > Upload files`).
2. Deponuzun **Settings > Pages** bölümüne gidin.
3. **Branch** kısmından `main` (veya `master`) seçip **Save** butonuna tıklayın.
4. Siteniz birkaç dakika içinde `https://kullaniciadiniz.github.io/depo-adi/` adresinde yayına girecektir!
